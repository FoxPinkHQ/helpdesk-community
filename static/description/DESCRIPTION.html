Full-featured helpdesk and support ticket management. Free, open-source, and production-ready.

Features

Ticket Management

Create, assign, track, and close support tickets with ease.

Pipeline Stages

Customizable pipeline: New → In Progress → Resolved → Closed. Drag-and-drop in kanban.

Teams & Agents

Organize agents into teams. Assign tickets to specific team members.

Customer Portal

Customers can create and track tickets via the portal — no agent login required.

Email Notifications

Automatic notifications on ticket assignment and stage changes.

Access Control

Three-tier permissions: User, Team Leader, Manager. Record rules per team.

Screenshots

Installation

Install directly from Odoo App Store, or clone the repository into your addons directory and update the apps list.

Configuration

  1. Go to Helpdesk → Configuration → Stages
  2. Go to Helpdesk → Configuration → Teams to add members
  3. Go to Helpdesk → Configuration → Categories
  4. Done — start creating tickets

Compatibility

✓ Odoo 19.0 Community & Enterprise

✓ No external services required

Open Core

This is the Community edition. Pro features (SLA, email gateway, automation, reporting) are available separately. Community edition is fully usable on its own — no artificial limitations.
