# FAQ

## General

### Is this module compatible with Odoo Enterprise?
Yes. All FoxPink modules are tested on both Odoo Community and Enterprise editions.

### Which Odoo versions are supported?
Currently: Odoo 19.0.

### Do I need technical skills to use this module?
No. The module is designed to work out of the box. Basic Odoo navigation skills are sufficient.

### Does this module require external services or API keys?
No, unless explicitly stated in the module description.

## Installation

### How do I install the module?
Install via Odoo App Store (one click), or clone the repo into your addons directory and update the apps list.

### Will this module affect my existing data?
No. The module only adds new functionality. It does not modify existing records.

## Troubleshooting

### The module doesn't appear in the apps list
1. Activate Developer Mode
2. Go to Apps → Update Apps List
3. Search again

### I found a bug
Please report it via [GitHub Issues](https://github.com/FoxPinkHQ/REPO_NAME/issues) with:
- Odoo version
- Module version
- Steps to reproduce
- Screenshots (if applicable)
