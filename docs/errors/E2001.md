# E2001 — Menu → model has no readable ACL

**Layer:** Compiler Validator (E2xxx) · **Invariant 13**

## Meaning

A `<menuitem>` / `ir.ui.menu` points (via its action) to a model for which
**no group at all** has a readable ACL (`perm_read=1`). The menu is invisible
to the entire instance.

## Why

Odoo filters `ir.ui.menu` entries by the read right on the action's
`res_model`. With zero readers, the entry is silently dropped from the UI.
Install succeeds and unit tests pass (they never assert menu visibility), so
the defect ships undetected until a human opens the app.

## Example

```
menu_helpdesk_tickets -> action helpdesk.action_ticket -> model helpdesk.ticket
ir.model.access.csv: no perm_read=1 row for helpdesk.ticket
=> E2001  Menu "Tickets" points to model "helpdesk.ticket" but NO group
         has a readable ACL.
```

## How to fix

Add a readable ACL for a group that should see the menu, typically:

```
access_helpdesk_ticket_user,helpdesk.ticket.user,model_helpdesk_ticket,base.group_user,1,1,1,0
```

For a community default module, also grant `base.group_system` so the
administrator sees the menu immediately after install.

## Severity

Error

## Invariant

13 — Menu Visibility (ADR-013)
