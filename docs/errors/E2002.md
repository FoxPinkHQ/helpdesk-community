# E2002 — Menu `groups` has no readable ACL

**Layer:** Compiler Validator (E2xxx) · **Invariant 13**

## Meaning

A `<menuitem>` / `ir.ui.menu` restricts visibility via `groups="..."`, but
**none** of those groups has a readable ACL (`perm_read=1`) on the action's
model. The menu's intended audience can never open it — even though some other
group might be able to read the model.

## Why

Odoo applies BOTH gates: the user must pass the menu's `groups` check AND hold
a read right on the action model. If the menu's groups lack that right, the
entry is hidden from exactly the people it was meant for.

## Example

```
menu_helpdesk_stages groups="helpdesk_community.group_helpdesk_team_leader,base.group_system"
model helpdesk.stage: readable ACL only for group_helpdesk_user
=> E2002  none of its groups (team_leader, base.group_system) has a readable ACL.
```

## How to fix

Grant read access to one of the menu's groups, or to `base.group_user` (which
`base.group_system` implies). Prefer granting the specific group that owns the
menu so the permission model stays intentional.

## Severity

Error

## Invariant

13 — Menu Visibility (ADR-013)
