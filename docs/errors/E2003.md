# E2003 — Menu action unresolvable to a res_model

**Layer:** Compiler Validator (E2xxx) · **Invariant 13**

## Meaning

A `<menuitem>` / `ir.ui.menu` declares an `action`, but that action cannot be
resolved to a `res_model` — either the action xmlid is missing/dangling, or it
is a server action / URL action that carries no model. Visibility cannot be
verified, so the check flags it rather than assume PASS.

## Why

`Invariant 13` needs the model to check the ACL chain. An unresolvable action
means the Compiler emitted a dangling reference (a real defect) or a model-less
action the validator cannot reason about. Both deserve a human look.

## Example

```
menu_foo action="action_bar"  -> action_bar not found in any XML
=> E2003  Menu "Foo" action "action_bar" not resolvable to a res_model.

<record model="ir.actions.server" id="action_job">
    <!-- no res_model field -->
=> E2003  (server action without res_model; cannot verify)
```

## How to fix

- Ensure the referenced action id exists and is loaded before the menu.
- For `ir.actions.act_window` / `ir.actions.report`, declare `res_model`.
- For genuinely model-less actions (e.g. `ir.actions.act_url`), the menu is
  intentionally not model-gated; mark it as known (no fix needed) once confirmed.

## Severity

Warning

## Invariant

13 — Menu Visibility (ADR-013)
