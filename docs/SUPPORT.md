# Support

- **Issues & bugs**: report via [GitHub Issues](https://github.com/FoxPinkHQ/REPO_NAME/issues)
- **Documentation**: included in the repository `docs/` folder

## Paid modules

- **Priority support**: support@foxpink.dev
- **Response time**: within 24 hours (business days)
- **Scope**: installation help, configuration, bug fixes
- **Not covered**: custom development, integration with third-party services

## Before contacting support

1. Check the [FAQ](FAQ.md) — your question may already be answered
2. Search existing [GitHub Issues](https://github.com/FoxPinkHQ/REPO_NAME/issues)
3. Restart Odoo and clear browser cache
4. Ensure you're on the latest version
