# Helpdesk Community

Odoo Helpdesk Community module — ticketing system with kanban, list, and form views,
team assignment, stages, portal access, and multi-version support.

## Installation

Install via Odoo Apps or:

```bash
./odoo-bin -d <db> -i helpdesk_community
```

## Usage

- Tickets are managed from the Helpdesk menu
- Supported views: Kanban, List, Form
- Portal access for ticket submission and tracking

## Version

This branch is for Odoo 16.0.
